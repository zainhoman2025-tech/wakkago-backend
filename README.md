# WakkaGo Backend

The central hub for **WakkaGo**: An on-demand logistics and delivery marketplace connecting businesses and individuals with verified vehicle operators (bikes, trucks, trailers, etc.).

## 🚀 Vision
WakkaGo aims to bridge the gap between people who need logistics services and the providers who offer them, ensuring trust through a "Commitment Fee" model and a flexible Escrow payment system.

## 🛠 Tech Stack
- **Framework:** Laravel (PHP)
- **Database:** PostgreSQL/MySQL
- **Real-time:** Pusher/WebSockets
- **Maps:** Google Maps API

## 📋 Core Backend Logic
- **The Connection Model:** Discovery and matching of nearby vehicles.
- **The Fuel Guarantee:** Automated calculation of distance and fuel costs to protect drivers from "waste of fuel" scenarios.
- **Escrow Toggle:** Provider-controlled payment preferences (Escrow vs. Direct).
- **Wallet System:** Automated commission splitting and provider payouts.
